# CAT Logic Lab

Private local CAT Logical Reasoning practice app.

## Chapters

- Games & Tournaments — Level 1: 41 questions, 11 sets
- Generic Puzzles — Level 1: 55 questions, 22 sets
- Combined: 96 questions

## Stack

React + TypeScript + Vite + lightweight CSS + localStorage.

## Run locally

```bash
npm install
npm run dev
```

## Notes

- No backend or authentication.
- Chapter data uses `Document → Sets → Questions` semantics.
- Progress, bookmarks, mistakes and practice answers are stored per chapter.
- Generic Puzzles uses Q1–Q55 only; LOD 2 is excluded.
- Generic Puzzles has no required LOD 1 visual assets.
- The existing Games & Tournaments source visuals remain unchanged.
